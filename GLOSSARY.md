# Peek

Peek lets you read messages from a conversation with a coding agent.

## Language

**Sent message**:
Text you submit to the agent, together with references to any attachments you
include. Automatically supplied instructions and context are not sent messages.

**Reply**:
A finished response from the agent to your sent messages.

**Unanswered message**:
A sent message for which the agent has not yet provided a finished reply.
